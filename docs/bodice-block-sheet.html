Engineering notes

  • Two circular formulas fixed. §4.6 and §5.7 each defined a dart intake in terms of itself. Total bust→waist reduction is now computed independently; each dart intake is that total minus what's already spent elsewhere.
  • Bust dart has no real formula. §5.5 bottoms out in a chest measurement this app doesn't collect. It's estimated from the bust–waist differential, clamped to the spec's 8–11cm range, and overridable per customer via eases.bustDartIntake.
  • Front waist dart = 0cm here — not a bug. The bust-dart estimate above already exceeds the available front reduction at this size, so no separate waist dart is needed.
  • front_shoulder_to_waist's CF conversion is approximate — §5.1's offset term was undefined in the spec; a real center-front tape reading will beat this default.
  • Regression tests pin current output, not a hand-drafted reference — no published block was available to validate against. Treat all "engine est." values as provisional.
